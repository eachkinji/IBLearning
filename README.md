# IB 网络与 NCP-AIN 备考学习系统

本仓库记录从网络基础学习 InfiniBand（IB）、GPU 集群网络并备考 NVIDIA NCP-AIN 的课程、实验与复盘。课程原稿和学习顺序以 [Notion「IB 网络」](https://app.notion.com/p/3e5e159bc71581afbd37fd89a83e7464) 为准；[完整学习路线](学习路线.md)概括了长期目标。

## 学习主线

1. 网络基础与 Linux：IP、MAC、交换、路由、网络命令
2. AI 算力集群：GPU 服务器、管理／存储／计算网络
3. InfiniBand 与 RDMA：Fabric、HCA、交换机、Subnet Manager、通信原理
4. 运维与设计：检查命令、排障、拓扑、带宽和冗余
5. 综合实践与 NCP-AIN 备考：设计方案、按考试大纲查缺补漏

## 每次学习怎么进行

1. 先不看笔记，回答一个回忆问题；再学习本课核心概念。
2. 完成测验和实验，记录实际答案、成绩及错因；未知项目保持“待完成”。
3. 复习时先凭记忆作答，再核对并改正；根据表现调整下一次日期。
4. 第 01 课达到测验 7/8、完成实验并能解释通信流程后，再进入下一课。

本地笔记只记录学习进度、自己的答案和脱敏实验结论。原始 `ipconfig /all` 等输出可能包含主机名、IP、MAC 等信息，请勿直接提交。完成记录后使用 `git add`、`git commit` 和 `git push` 同步到本仓库的私有 GitHub 远端。

# IB 网络学习记录

本仓库记录 InfiniBand（IB）网络系统课的学习、实验与复盘。课程原稿和学习顺序以 [Notion「IB 网络」](https://app.notion.com/p/3e5e159bc71581afbd37fd89a83e7464) 为准。

## 学习主线

1. 网络基础：IP、子网、交换、路由
2. 数据中心网络：拓扑、带宽、时延、拥塞
3. InfiniBand：Fabric、HCA、Switch、Subnet Manager
4. RDMA：基本原理与常见协议
5. 实操与认证：命令、排障、实验记录

# 第 02 课测验：IP 地址与子网掩码

不看笔记独立作答，格式如 `1B 2A 3C ...`。每题 1 分，共 8 分；目标至少 7/8。题目使用普通 IPv4 以太网环境；默认网关已配置并可达。答完后记录实际答案与错因，不预填成绩。

1. `192.168.4.9/26` 中的 `/26` 表示什么？A. IP 地址要除以 26；B. 前 26 位是网络前缀；C. 有 26 台主机；D. 第四段必须是 26。
2. 与 `/25` 等价的子网掩码是：A. `255.255.255.0`；B. `255.255.255.192`；C. `255.255.255.128`；D. `255.255.254.0`。
3. A 为 `10.4.7.70/26`。以下哪个地址与 A 同子网？A. `10.4.7.120`；B. `10.4.7.50`；C. `10.4.7.130`；D. `10.4.8.70`。
4. A 为 `192.168.10.8/23`。以下哪个地址与 A 同子网？A. `192.168.9.8`；B. `192.168.8.200`；C. `192.168.12.8`；D. `192.168.11.200`。
5. A 为 `172.16.14.5/22`。以下哪个地址与 A **不在**同一子网？A. `172.16.12.9`；B. `172.16.13.9`；C. `172.16.15.9`；D. `172.16.16.9`。
6. A 为 `10.1.18.5/21`。哪个第三段范围与 A 同子网？A. `16–23`；B. `8–15`；C. `18–25`；D. `20–27`。
7. 关于 `192.168.12.0/22`，哪项正确？A. `192.168.12.0` 一定是默认网关 IP；B. `192.168.12.0` 是网关 MAC；C. `192.168.12.0` 是该子网的网络地址，无法仅据此推出网关 IP；D. `/22` 表示网关有 22 个端口。
8. A 发往另一个子网的 C，且已知默认网关的 MAC。A 发出的数据帧通常如何填写目的地址？A. 帧目的 MAC 为 C 的 MAC，IP 包目的 IP 为网关 IP；B. 帧目的 MAC 为网关 MAC，IP 包目的 IP 为 C 的 IP；C. 两者都是网关地址；D. 两者都是 C 的地址。

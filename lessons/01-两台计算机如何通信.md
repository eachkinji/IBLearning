## 核心路线

同一 IPv4 以太网中的 A 向 B 发送数据（以 TCP 应用为例）：

```text
应用数据 → TCP → IP 包 → 以太网帧 → 网卡 → 交换机 → B 的网卡与协议栈 → 应用
```

发送前，A 根据子网掩码判断目的 IP 是否在本地子网。本地目标需要对应的 MAC；跨子网目标通常需要默认网关的 MAC。ARP 可在相关 IPv4 以太网链路上解析这个映射。二层交换机按目的 MAC 转发以太网帧，路由器按 IP 路由信息把包转发到其他网络。这是 TCP/IP over Ethernet 的教学流程，不能直接当作原生 InfiniBand 的协议流程。

## Windows 实验

在联网的 Windows 电脑上运行。记录结果时请脱敏，不提交原始命令输出。

```powershell
ipconfig /all
ping 127.0.0.1
ping <实际默认网关 IP>
ping 1.1.1.1
arp -a
```

- [x] 找到正在联网的网卡、IPv4、子网掩码、默认网关、MAC（仅记录脱敏结论）
- [x] 完成环回、真实网关、公共 IP 的 Ping（学习者报告均成功）
- [x] 在 ARP 缓存中尝试找到网关 MAC（学习者报告已看到）

实验结论（脱敏）：在有线网卡上找到所需地址；本机与默认网关处于同一 `/24` 子网。学习者报告三次 Ping 均成功，ARP 中能看到网关项；首项回复「成果」暂按「成功」理解。未记录原始输出或具体地址。
